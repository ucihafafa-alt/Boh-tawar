Бөх Таавар Pro v3.1

Энэ нь v2 дээр суурилсан линкээр ашиглах PWA хувилбар.

Шинэчлэлт:
- app.js задлаад js/ модулиуд болгосон
- Профайл зураг, аймаг, нас нэмсэн
- XP, Level, Medal систем нэмсэн
- Countdown timer нэмсэн
- Олон наадам/барилдаан сонгох хэсэг нэмсэн
- Бөхийн мэдээлэл string биш object болсон: нэр, цол, аймаг, зураг
- Чансаа ТОП 100, аймгаар шүүх боломж нэмсэн
- Админд наадам нэмэх, бөх нэмэх, үр дүн оруулах хэсэг сайжирсан
- PWA cache сайжирсан

Ажиллуулах:
1. index.html файлыг Chrome дээр нээнэ.
2. Нэр + утсаар бүртгүүлнэ.
3. Таавар өгнө.
4. Админ хэсэг: PIN 1234.
5. Үр дүн оруулаад оноо автоматаар бодно.

Анхаарах:
- Энэ нь бодит мөнгөний бооцоот систем биш. Оноотой тааврын PWA prototype.
- Өгөгдөл browser-ийн localStorage дээр хадгалагдана.
- V4 дээр Firebase Auth, Firestore, realtime leaderboard холбоно.
